【数据说明 · 打开即实时】
- 架构：data.js 存「收盘基础」（每只近 61 个交易日收盘 closes + 250 日前收盘 c250 + 基准日 baseDate）；
  每次打开页面，live-refresh.js 用【一次批量行情】拿全 A 股最新价 →
  用 closes + 今日价 重算 w5/w20/w60/w250 → 用真实 six-engine 重跑六派/三态 → 重渲染。
- 交易时段：今日价=实时价 → 盘中实时结论；非交易时段/节假日：接口返回最后收盘价 → 自动为「收盘统计」。
- 盘中每 60s 自动刷新一次，切回标签页立即刷新；左下角角标显示「盘中实时 / 收盘数据 + 时间 + 重算只数」。
- 生成/刷新基础数据：python tools/build_data.py --universe full
  （零依赖，只用系统自带 curl，无需 pip 安装任何包；约 5000+ 只，10~20 分钟）
  行业归属：python tools/fetch_industry.py （可选，让「行业」页有内容）
- 行情多源降级：批量东财（全市场）→ 单只东财/腾讯/新浪（搜索/透镜）；失败回退快照并明确标注。

【分享给别人用（公网访问）】
1. python tools/build_site.py   → 生成 dist/（只含运行必需的 12 个文件，
   不含 项目上下文/、tools/、tests/ 等开发与私人材料）
2. 把 dist/ 整个目录上传到任意静态托管（WorkBuddy「发布应用」/ Vercel /
   Netlify / Cloudflare Pages / GitHub Pages 均可），即可得到一个可分享的网址。
3. 别人打开该网址：浏览器自动加载 data.js → 实时抓全 A 股行情 → 重算六派/三态
   → 直接看到结论。对方无需安装任何东西，也无需本机开服务。
   注意：实时行情由「访问者自己的浏览器」直连东财/腾讯/新浪，因此对方网络需要能访问这些接口。

【数据源优先级与降级】
- 原则参照开源项目 simonlin1212/a-stock-data：按「封 IP 风险」排序，而不是按数据丰富度。
  腾讯（不封 IP，K 线 3 个入口轮换）> 交易所/官方 > 新浪/巨潮 > 东财（有风控，仅用于独有数据，必须限流）
- 浏览器端能用：腾讯 K 线（_var= 赋值式，等价 JSONP）、腾讯实时 46 字段、东财搜索（资讯）、东财 datacenter（财报）
- 浏览器端用不了（已实测，别再试）：东财 push2his（加 cb 返回空、无 CORS）、新浪 K 线（忽略 callback、无 CORS）
- 完整对标与实测记录见：GitHub对标_a-stock-data_借鉴清单.md

【常见问题】
- K线图一直转圈？—— 那是在真实请求前复权日K（不是假加载），整体上限约 9 秒；
  超时/失败会明确标缺口，绝不编造数字。建议先跑一次 regen_offline.py 生成离线数据。
- 为什么是全市场约 5000 只而不是 158？—— 已改为腾讯 / 新浪免费行情拉全 A 股重算（零依赖，无需安装任何包）；运行 `python tools/build_data.py --universe full` 刷新（加 `--fund` 含主力资金流，六派资金派才完整）。
- 右下角绿/黄/红小圆点？—— 运行时自检徽标，点开看详情；
  含数据完整性 / 三态一致性（用真实引擎重算 vs 快照）/ 日K质量等 5 类检查。
- 页面样式旧 / 新页面 404？—— 浏览器缓存问题：网址后加 ?v=20261125c 强制刷新。
